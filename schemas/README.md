# Draft final-provider usage record — revision 2

This is a provider-usage format/normalizer draft, not the complete broker/controller event schema or a launch qualification. Only the observed GLM/Relace mapping is registered in the current normalizer; other model/provider mappings must be verified and added before integration.

Final provider observations retain raw snapshots and nullable unavailable counters. Prompt input includes cache subsets. Equal cache-creation/write aliases are selected once; conflicting non-null aliases fail reconciliation. Reasoning remains diagnostic and is never added to billed completion. Metadata enums, model/provider/mapping combinations, nested detail types and finite nonnegative cost are validated. Actual route resolution, actor/session ancestry and timing still require trusted controller evidence; a source label or content hash is not independent proof of provenance.

Record IDs hash canonical JSON tuples, not ambiguous delimiter joins. Duplicate provider responses must have the same attribution/mapping; different sessions/actors/mappings cause an unresolved conflict rather than two charges. Known final totals cannot change silently. A later incomplete observation cannot erase known counters/cost; all distinct raw snapshots and warnings are retained. Conflicting records remain in the raw event store even when normalization/reconciliation raises an error. Callers must not convert failures to zero usage.

Only final observations belong in this schema. Partial streaming deltas remain raw events until the collector establishes final observation semantics. Failed calls lacking usage/response IDs stay separate attempt/error events with unknown usage. Native steps, generation lookups and invoices are other views, not additional billable calls. The schema intentionally cannot claim `crosschecked`; native joins and actual model/provider evidence remain unverified until a later integration schema supplies corroboration.

Revision 2 addresses Terra's U1/U2 source-level findings. Different-model cross-review of these revisions, final controller/broker integration, all-model mappings, endpoint timing/ancestry and complete capture remain pending. Earlier source/review/probe records are preserved in Git.
